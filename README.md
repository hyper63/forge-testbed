# forge-testbed

A throwaway repository for verifying Forge runs end to end. Nothing here
matters; it exists so a develop run has somewhere to work.

## Layout

| Path | What it is |
| --- | --- |
| `src/greet.js` | A greeting function |
| `test/greet.test.mjs` | Its tests |

## Scripts

| Command | Does |
| --- | --- |
| `npm test` | Run the Node test suite |
